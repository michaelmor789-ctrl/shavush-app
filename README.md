# שבו״ש · אחראים ושבושים

אפליקציה (PWA) לאחראים ולהנהלת בעוז הרוח.

## הגדרות (לפני עליה לאוויר)
ב-`index.html`:
- `DB` — כתובת Firebase Realtime Database של שבו״ש (פרויקט נפרד מאפליקציית הלוז)
- `STAFF_PASSWORD` — סיסמת צוות לשבו״ש

כללי Firebase חייבים להיות מוגבלים לפני שמשתפים את הקישור (הנתונים כוללים טלפונים).
